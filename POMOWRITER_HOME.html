User Guide

사용 방법

가이드 북까지 읽어야 했던 복잡한 프로그램은 잊으세요. 항목을 눌러 펼치면 자세한 사용 방법을 확인할 수 있습니다.

시작 화면 & 작품 리스트+
  • 필명과 작품 상태를 바탕으로 필터하여 작품 목록을 볼 수 있습니다.
  • 작품 카드를 더블 클릭하면 집필 화면으로 이동합니다.
  • 작품 카드 하단의 […] 아이콘을 통해 작품 내용을 수정할 수 있습니다.
  • 메인 메뉴에서 잠금 설정을 해두면, 프로그램 시작 전에 비밀번호 입력창이 팝업됩니다.
메인 메뉴+
  • 새 작품 추가 — 새로운 작품 파일을 생성합니다.
  • 로컬 열기 — 로컬(내 문서\PomoWriter Projects\)에 있는 작품 파일을 불러옵니다.
  • 구글 열기 — 로그인한 계정의 구글 드라이브에 업로드한 작품을 불러옵니다. (로그인 상태에서 가능)
  • 로컬 저장 — 로컬 파일 저장 경로에 저장합니다.
  • 구글 동기화 — 작업 중인 작품의 데이터 파일을 로그인한 구글 드라이브(PomoWriter Projects 폴더 안)에 업로드합니다.
  • 자동 동기화 ON/OFF — 백그라운드 동기화 작업을 켜고 끌 수 있습니다.
  • 로그인 / 로그아웃 — 구글 드라이브 동기화와 불러오기를 위한 구글 계정 로그인·로그아웃.
  • 배경색 설정 — 에디터 배경 색상을 변경합니다.
  • 다크 모드 — 다크 모드와 라이트 모드로 전환합니다.
  • 잠금 설정 — 프로그램에 비밀번호를 걸어 잠글 수 있습니다. (비밀번호는 내 문서\PomoWriter Projects 폴더 안 txt 파일에 저장되며, 잊은 경우 해당 경로에서 확인할 수 있습니다.)
  • 파일 변환 — 작품 내용을 한글 파일 또는 PDF 파일로 변환합니다.
  • PomoWriter 안내 — 개발자 정보, 홈페이지 주소, 프로그램 버전 정보를 확인하는 창입니다.
메뉴바 & 에디터+

메뉴바 구성: 폰트 설정 / 폰트 크기 / 굵게 / 기울임 / 밑줄 / 들여쓰기 / 내어쓰기 / 폰트 색상 / 폰트 배경 색상 / 줄 여백 / 문단 여백 / 에디터 폭 너비 / 듀얼 모드 / 뽀모도로 / 집중 모드

  • 듀얼 모드 — 집필창을 두 개 동시에 열어두고 사용하는 기능. 여러 버전을 비교하거나 퇴고할 때 유용합니다.
  • 뽀모도로 — 🔥 집중 시간 / 💧 휴식 시간 / 🎵 집중 음악 ON·OFF.
  • 집중 모드 — 설정한 뽀모도로 집중 시간 동안 오로지 집필에만 몰두하는 기능. Backspace·Del 키를 사용할 수 없어 초고 작업이나 마감이 임박했을 때 유용합니다.

에디터 영역

  • 시계 🕐 — 열려 있는 에피소드 파일의 버전을 확인하거나 불러옵니다.
  • 돋보기 🔎 — 에디터 텍스트를 분석합니다. (대사·지문 비율 / 문장 길이 / 자주 등장하는 단어 / 연속된 지문과 문장 어미 필터)
  • 해 — 에디터의 해상도를 조절합니다.
시놉+
  • 제목 옆 '작품 상태'로 구상/집필/투고/계약/무연/출간/연재/자료/기타를 선택할 수 있습니다.
  • 키워드 입력은 키워드 옆 🔎돋보기를 눌러 팝업창에서 키워드를 클릭하면 자동으로 입력됩니다.
  • 시놉을 한글 파일 또는 PDF 파일로 변환할 수 있습니다.
로그+
  • 상태 — 집필 상태를 구분할 수 있는 항목입니다.
  • 글자수 — 회당 글자수를 기록합니다. (바인더에서 에피소드 이름을 1, 01, 001처럼 숫자로 설정해두면 회차 1의 글자수를 자동으로 불러옵니다.)
  • 여주·남주 — 회차마다 등장 인물의 등장 여부를 표시합니다. 상단의 인물 추가·삭제 버튼으로 관리합니다.
  • 장면 — 회당 장면 수를 기록합니다. ('***'로 장면을 나누면 자동으로 집계됩니다.)
  • 등장한 떡밥 — 실제로 집필한 떡밥을 기록합니다. 떡밥은 콤마로 구분됩니다. 미회수 떡밥은 분홍색, 회수된 떡밥은 회색으로 표시되며, 클릭하면 상세 설명을 입력할 수 있고, 마우스를 올리면 등장·회수 회차와 설명이 팝업됩니다.
  • 회수한 떡밥 — 실제로 회수된 떡밥을 기록합니다.
  • 하단 프레임 — 회차당 평균 글자수와 작품의 총 글자수를 표시합니다.
플롯+
  • 박스 추가 — 우클릭하여 박스 추가 합니다.
  • 상세 패널 — 박스를 더블 클릭하면 상세 패널을 열고 닫을 수 있습니다.
  • 박스를 우클릭하면 내용 수정과 색상 변경이 가능합니다.
  • 박스를 드래그하여 발단/전개/위기/절정/결말에 맞춰 순서를 배치할 수 있습니다.
  • 에피소드 순서를 입력하면 에피소드 별로 박스를 묶어서 배치 할 수 있습니다..
구조+
  1. 작품의 스토리를 5문장으로 만들어 상위 5막 구조에 입력합니다.
  2. 그 5문장을 한 문장 당 5개로 쪼개어 중위 5막 구조에 입력합니다.
  3. 중위 5막 구조의 내용을 다시 5개로 쪼개어 하위 5막 구조에 입력합니다.

기승전결로 구성한다면 '위기' 또는 '결말' 단계를 비워두면 편합니다. 단편은 중위 단계까지, 초단편은 상위 단계까지만 입력해도 충분하며, 모든 구간을 채우지 않아도 됩니다.

에피+
  • 탭 추가 — 상단의 [+탭]을 눌러 정리할 에피소드 탭을 추가합니다.
  • 탭 삭제 & 이름 변경 — 탭 이름에 우클릭해 삭제하거나 이름을 변경합니다.
  • 탭 순서 변경 — 이동할 탭 이름에 우클릭해 좌우로 순서를 옮길 수 있습니다.
트릿+
  • 항목설정— 트리트먼트를 기록할 항목을 추가 혹은 삭제 할 수 있습니다.
  • 트리트먼트를 작성할 회차를 선택하고 각각의 항목에 알맞게 입력합니다.
타임+
  • 전체화면으로 보기 — 좌측 상단 모서리의 하트를 눌러 넓게 볼 수 있습니다.
  • 날짜 연장 — 상단의 [날짜 연장] 버튼으로 날짜를 추가합니다.
  • 사건·인물 추가 — 상단의 [항목 추가] 버튼으로 사건이나 인물 트랙을 추가합니다.
  • 박스 추가·이동·복사·삭제 — 원하는 위치에 우클릭해 추가하고, 드래그로 이동하며, 우클릭으로 복사·삭제·내용·색상을 수정합니다.
  • 박스 연장 — 우클릭 → [내용 수정]에서 지속일을 늘릴 수 있습니다.
  • 날짜·트랙 이동 — 우클릭으로 위치와 순서를 변경합니다.
캐릭+
  • 캐릭터 추가·삭제 — 상단의 [캐릭터 추가] 버튼으로 탭을 추가, [현재 캐릭터 삭제]로 제거합니다.
  • 능력치 — +로 그래프를 추가. 모서리 부분을 클릭해 명칭과 수치를 수정합니다.
  • 캐릭터 이름을 '성 이름' 순으로 띄어 쓰면, 에디터에서 그 이름을 쓸 때마다 캐릭터의 눈동자·머리색이 팝업됩니다. '서양식'에 체크하면 '이름-성' 순으로 인식합니다.
  • 여주인공과 남주인공으로 설정한 캐릭터의 프로필 사진을 선택하면 [관계]의 '여주인공'과 '남주인공'노드에 프로필 사진이 적용됩니다.
감정+

감정 그래프를 그리려면 먼저 [사건 추가]와 [인물 추가]가 필요합니다.

  • 사건 추가 — 상단의 [+사건]으로 추가하고 드래그로 위치를 옮길 수 있습니다. 시간 흐름을 보고 싶다면 사건 대신 '월·일'을 입력해도 됩니다.
  • 인물 추가 — 상단의 [+인물]로 추가하고 그래프 색상을 선택합니다.
  • 감정 그래프 그리기 — [+감정]에서 인물·사건·감정을 선택하고 내용과 이유를 입력합니다. 그래프 점에 마우스를 가져가면 '이유'가 팝업됩니다.
  • 탭 추가·삭제 — [탭+]/[탭-]로 관리하며, 사건·인물·그래프 모두 우클릭으로 수정·삭제할 수 있습니다.
관계+
  • 탭 추가·삭제 — [탭+]/[탭-]로 관리합니다.
  • 인물 추가 — [+인물]로 추가합니다. (여주·남주는 [캐릭] 메뉴에서 설정한 이미지로 노드가 생성됩니다.)
  • 그룹 추가 — [+그룹] 클릭 후 드래그하면 그룹 영역이 표시됩니다.
  • 전체화면 작업 — [전체보기]로 넓게 작성하고, 인물 노드를 더블 클릭하면 상세 패널이 열립니다.
  • 인물 연결 — 인물에 우클릭 → '연결하기' → 연결할 인물 선택 → 관계명 입력.
  • 수정·삭제 — 관계선·그룹·탭 모두 우클릭으로 이름·색상 변경, 삭제가 가능합니다.
  • 탭 이름을 에디터에 작성하면 해당 탭 정보가 팝업됩니다. 로판일시, 가문별로 가계도를 만들어놓으면 이름을 오타없이 입력할 수 있습니다.
마인+
  • 하위 노드 추가 — 상위 노드에 우클릭 또는 + 버튼으로 추가합니다.
  • 노드 수정·이동 — 우클릭으로 이름·색상을 변경하거나 삭제하고, 드래그로 이동합니다.
  • 화면 이동 — 바탕화면이나 하단 맵을 드래그해 영역을 이동합니다.
  • 전체 화면 작업 — 상단의 [전체 보기] 버튼으로 넓게 작업합니다.
메모+
  • 메모 추가 — 상단의 [새 메모 추가] 버튼으로 추가합니다.
  • 분류 추가·삭제 — [+분류 추가], [분류 삭제]로 관리합니다.
  • 메모 순서 이동 — 메모 번호 앞 드래그 버튼으로 순서를 바꿉니다.
배치+

탭 추가·삭제 — 상단의 [+탭 추가], [탭 삭제] 버튼으로 관리합니다.

도구: 이동 / 펜 / 선 / 사각 / 원 / 채우기 / 글자 / 지우개 / 선 색상 / 투명(채움색) / 두께.

채움색을 먼저 선택한 뒤 도형을 그려야 안쪽이 채워집니다.

작명+

랜덤으로 이름을 생성하고자 하는 [장르-성별]버튼을 누르면 이름이 생성됩니다. 생성된 이름을 클릭하면 바로 복사됩니다.

단어+

국립국어원 한국어기초사전과 우리말샘 데이터를 참고해 만들어, 검색한 단어의 파생어·관용구·속담까지 찾을 수 있습니다.

  • 단어 검색 — 단어를 입력하고 검색 버튼 클릭 또는 엔터.
  • 단어 수집 — 검색 결과에서 드래그 → 우클릭 → [작가 사전에 추가] → 작품·태그 선택 후 저장.
  • 작가 사전 이용 — [+작품]으로 작품 추가 → [분류 태그 +]로 태그 추가 → 표현을 입력하고 저장. 상황별·감정별 태그로 정리하면 작품마다 반복되거나 중복되는 표현을 줄일 수 있습니다.
KEY+

상단에서 플랫폼을 선택해 키워드를 확인하고, 하단의 [랜덤 조합] 버튼으로 키워드를 무작위로 생성합니다.

TTS+

사용 순서: 확인할 조판 선택 → [원고 가져오기] → 서식 조절 → 음성 선택 → 속도·피치 조절 → 재생. (오류를 줄이기 위해 이 순서를 권장합니다.)

  • 원고 가져오기 — 좌측 메인 에디터의 텍스트를 자동으로 불러옵니다.
  • 음성 목록은 사용 중인 컴퓨터 환경에 따라 다를 수 있습니다.
  • 재생 중에는 페이지 이동이나 조판 안의 글자 수정을 피해주세요.
  • 더 다양한 음성으로 듣고 싶다면 [PDF나 EPUB으로 변환->핸드폰으로 이동-> 이펍 어플로 열기]하여 들어보세요.
이펍+

사용 순서: 변환할 에피소드를 메인 에디터에서 선택 → [원고 가져오기] → 편집 모드(✏️ 아이콘)→ 제목·상태창·메세지·이미지 추가할 위치나 쪽나누기할 위치에 마우스 클릭 → 추가하고자 하는 버튼 클릭하여 추가. → 뷰어 모드(👁️ 아이콘)로 미리보기 → [EPUB 파일 저장].

*뷰어 모드는 예시 화면일 뿐이며, 실제 EPUB 뷰어에서 보이는 화면과 다를 수 있습니다.*

투고+
  • [투고일]과 [회신일]을 YY-MM-DD 형태로 입력하면 [회신 기간]이 영업일 기준으로 자동 계산됩니다.
  • [투합 여부]·[자사 양식]·[피드백]은 클릭으로 빈칸/O/X를 전환합니다. 투합 여부가 O면 자동으로 투합탭에 생성됩니다.
  • 상단의 [작품 선택]으로 다른 작품의 투고 현황도 확인·입력할 수 있습니다.
  • 투합탭에서 [계약 체결]을 체크하면 계약탭 목록에 자동 생성됩니다. [계약탭]의 '+계약 추가'로 출판사와 계약 작품을 입력합니다.
  • 완고일·런칭일·표지 제안서 마감일을 입력하면 [일정] 캘린더에 자동으로 일정이 추가됩니다.
수익+
  • 상단 탭에서 작업 중인 작품과 전체 작품의 수익을 월별/연도별/연재 유형별로 확인합니다.
  • 줄 추가 / 플랫폼 추가 — [+ 줄 추가], [+ 플랫폼 추가]로 항목을 늘립니다. 플랫폼은 우클릭으로 이름·순서를 변경합니다.
  • [시놉]에서 설정한 유형(연재/단행/초단)과 작품 리스트의 필명을 기준으로 수익이 자동 분류됩니다.
  • [합계]는 월별 수익, [total]은 전체 합산을 보여줍니다.
일정+
  • 일정 추가 — [+일정 추가]로 내용과 기간을 입력하면 달력에 생성됩니다.
  • 일정 수정·삭제 — 달력에서 우클릭해 수정하거나 삭제합니다.
  • 디데이 추가 — [+일정 추가] 또는 [일정 수정]에서 [중요 D-DAY]를 체크하고 저장합니다.
  • 할 일 추가 — 입력창에 할 일을 적고 엔터를 누릅니다.
일지+
  • 월 목표 — 입력칸에 목표를 작성하고 엔터를 누릅니다.
  • 작업 데이터 — 작품명, 작업 유형(구상/초고/퇴고/작교/인풋/기타, 복수 선택 가능), 시작·종료 시간, 총 작업 시간(분), 글자수, 기분(복수 선택 가능), 인풋한 작품·회차를 기록합니다.
  • 할 일 — [일정]에서 입력한 할 일을 확인·추가할 수 있습니다.
  • 통계 — 해당 월·연도의 작업일 수와 누적 글자수를 확인합니다.
  • 하루 목표 글자수 — 목표치를 설정하면 한 달간의 달성 현황을 그래프로 볼 수 있습니다.
  • 일지 — 선택한 날짜의 일지를 자유롭게 입력합니다.
출판사 관리+

하단의 '출판사 추가'로 출판사를 추가하거나, 상단의 '설정' 버튼으로 출판사를 추가·삭제하고 기록하고 싶은 항목을 추가할 수 있습니다.
