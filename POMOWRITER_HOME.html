설치 전 꼭 확인해 주세요
· 내려받은 설치 파일(PomoWriter-Setup-2.3.0.exe)을 실행하면 관리자 권한 없이 설치됩니다.
· 새 버전이 나오면 프로그램 안에서 업데이트 알림이 뜨고, [지금 업데이트]를 누르면 자동으로 내려받아 설치·재시작됩니다. 홈페이지에서 다시 받을 필요가 없습니다.
· 작성한 작품 파일(내 문서\PomoWriter Projects)은 업데이트·재설치와 무관하게 그대로 유지됩니다.
· 업데이트 후에는 보안을 위해 로그아웃 상태가 됩니다. 구글 계정을 다시 로그인해 주세요.
· 비용 문제로 프로그램에 서명이 되어 있지 않아, 첫 실행 시 보안 알림이 뜰 수 있습니다. [추가 정보] → [실행]을 누르면 정상 실행됩니다. 컴퓨터 보안 설정이 높다면 첫 실행 시에만 보안을 낮춰 주세요.

2026.10.21 업데이트최신+
  1. [이펍] 편집 모드와 뷰어 모드를 하나로 합쳤습니다.
    • 뷰어 모드와 편집 모드를 번갈아 가며 이펍 파일을 만들던 것을 하단의 박스들을 드래그하는 것으로 수정하여, 이미지 첨부 및 제목 삽입 등의 기능이 편리하고 결과를 한눈에 보기 쉬워졌습니다.
  2. [캐릭] 항목 편집 방식 변경 및 양식(프리셋) 기능 추가.
    • [✎ 편집] 모드에서 항목을 드래그하여 이동 및 배열을 변경할 수 있습니다.
    • [Ctrl+클릭]을 하면 여러 항목을 한 번에 이동시킬 수 있습니다.
    • [양식] 버튼을 통해 지금의 항목 구성을 저장하고, 다른 캐릭터 혹은 다른 작품에서 사용할 수 있습니다.
    • 참고 이미지가 캐릭터마다 3칸에서 5칸으로 늘었습니다.
  3. 한글·워드 문서 불러오기 기능 추가.
    • 메인(구름) 메뉴의 [한글 불러오기]를 통해 한글·워드 파일의 텍스트를 불러올 수 있습니다.

  5. '/'를 이용한 특수기호 입력 기능 추가.
    • 에디터 영역에서 '/'를 입력하면 특수기호 표(「 」 『 』 【 】 ☆ ★ ♪ ♡ 등 44개)가 뜹니다.
    • 방향키와 Enter(또는 마우스)로 고르고, Esc 혹은 백스페이스바로 닫을 수 있습니다.
    • '그/그녀'나 날짜를 쓸 때 방해되지 않습니다.
  6. [작업 현황] 메뉴 추가.
    • 메인 메뉴(구름 아이콘)의 메뉴에 [작업 현황]을 추가하였습니다.
    • [작업 현황]에서는 출석(연속 출석일 포함), 프로그램 사용 시간, 타이핑 시간·집중도, 타이핑 글자 수와 시간당 평균, 뽀모도로 집중·휴식 시간과 횟수, 서브 메뉴 사용 시간을 일간·월간·연간 탭으로 확인할 수 있습니다.
    • 글자 수는 '공백 포함'과 '공백 제외' 중에서 고를 수 있고, 처음 기준은 '공백 포함'입니다.
    • 월간·연간 그래프의 막대에 마우스를 올리면 그날·그달의 타이핑 글자 수가 말풍선으로 표시됩니다.
    • 붙여넣기·불러오기·에피소드 복사·휴지통 복구로 늘어난 글자 수와 Backspace·Del 키로 삭제한 글자 수는 타이핑 글자 수에서 제외됩니다.
    • [일지]를 열면 작품명(작품마다 태그)·총 작업 시간·글자수가 자동으로 입력됩니다.
  7. 버그 수정 및 편의성 개선
    • 자동 저장과 버전 기록 방식을 개선하여, 프로그램 작동을 더 가볍게 했습니다.
    • 버전 기록 기능을 켜고 끌 수 있는 ON/OFF 버튼을 추가하였습니다.
    • [트릿]·[투고]·[캐릭]·[인풋]·[에피]의 손잡이 버그를 수정하였습니다.
    • [맞춤법] 오류를 수정하였습니다.
    • 듀얼 보기에서 지워진 항목을 참조할 때 발생하는 오류를 수정하였습니다.
    • [이펍] 버튼에 마우스를 올릴 때 뜨는 설명창 글자가 보이지 않던 문제를 수정했습니다.
    • [타임] 카드형 '전체보기'가 보이지 않던 문제를 수정했습니다.
    • 글자수가 많아지면서 발생하던 딜레이 및 버벅거림 문제를 개선했습니다.
    • [로그인]과 [로그아웃]을 하나로 합치고, 로그인한 계정의 이름을 표시하였습니다.

    • [작명]과 [KEY]는 언어에 맞는 데이터를 보여 줍니다. 영어·일본어 설정에서는 그 언어의 이름·지명(현대·로판·판타지)과, 영어권(Royal Road·Wattpad 등)·일본(소설가가 되자·カクヨム 등) 웹소설 플랫폼의 키워드가 표시됩니다.
  2. [로그] — 회차 수 관리.
    • 새 작품은 기본 50화로 시작합니다. 이미 만들어 둔 작품의 회차 수는 그대로 유지됩니다.
    • [+ 10회차] 버튼이 [회차관리]로 바뀌어, 회차를 원하는 만큼 늘리거나 줄일 수 있습니다. (입력한 내용이 있는 회차보다는 줄일 수 없습니다.)
    • 바인더의 에피소드가 지금 회차 수보다 많아지면 회차가 자동으로 늘어납니다.
  3. [메모] — 게시판 그림 크기 조절.
    • 게시판 본문의 그림을 클릭하면 선택되고, 오른쪽 아래 손잡이를 끌어 크기를 바꿀 수 있습니다.
    • 그림을 오른쪽 클릭하면 25%·50%·75%·원본 크기·본문 너비에 맞춤·직접 입력을 고를 수 있고, Delete 키로 지울 수 있습니다.
  4. [서브 메뉴바] 아이콘 추가 및 표시 방식 설정.

    • 메인(구름) 메뉴의 아이콘도 더 깔끔한 선 아이콘으로 바꾸었습니다.
  5. 도구 패널을 별도 창으로 분리.
    • 서브 메뉴 패널의 머리 부분을 메인 창 밖으로 끌어내거나 ⇱ 버튼을 누르면 독립된 창으로 분리되고, 창을 메인 창 위에 놓거나 ⇲ 버튼을 누르면 다시 합쳐집니다. 모니터 가장자리로 끌어 화면을 분할하는 윈도우 스냅도 지원합니다.
  6. 안드로이드 앱을 위한 이미지 동기화.
    • 캐릭터·아이템 이미지(와 표지)도 구글 드라이브 동기화에 포함됩니다.
    • 업데이트 후 첫 실행에서 기존 작품의 이미지를 자동으로 한 번 올립니다(개인 PC 모드, 로그인 상태에서 진행되며 진행 안내창이 표시됩니다).
  7. 새 로고·아이콘 적용.
    • 프로그램·파일·메뉴·로딩 화면과 작품 목록창의 로고를 새 디자인으로 바꾸었습니다.
    • .pmw 파일 아이콘이 설치 후에도 제대로 표시되도록 등록 방식을 고쳤습니다(업데이트 후 첫 실행 때 적용).
  8. 팝업·기본 위젯 디자인 정리.
    • 색 선택창과 확인·입력·진행률 창이 앱 디자인(라이트/다크)에 맞는 모양으로 바뀌었습니다.
    • 체크박스·슬라이더·진행 막대 등 기본 위젯의 모양을 앱 색상에 맞췄고, [배치]·[수익] 화면의 색 톤을 다른 메뉴와 맞췄습니다.
  9. 버그 수정과 편의성 개선.
    • 도구 패널 헤더의 ⤢ 버튼으로 집필실을 접어 패널을 넓게 쓸 수 있고, [?] 도움말 창이 다크 모드를 따릅니다. 버튼·목록 위에서도 창 가장자리를 끌어 크기를 바꿀 수 있습니다.
    • 창을 최대화한 뒤 타이틀바를 끌어 옮기면 창 크기 조절이 되지 않던 버그를 수정했습니다.
    • [타임] — 날짜 머리를 끌어 날짜 순서를 바꿀 수 있고, 드래그가 가끔 먹히지 않던 문제와 트랙·날짜를 옮길 때 생기던 오류를 수정했습니다. 박스에 '몇 화'와 획득한 아이템 태그가 표시됩니다.
    • [관계] 인물 추가창에 캐릭터 이름 검색 목록이 생겼고(↑↓·Enter·Esc 지원), [캐릭] 프로필 사진을 삭제할 수 있습니다.
    • [바인더] — 다크 모드에서도 아이콘이 유지되고 마지막으로 열었던 항목이 복원됩니다. 열려 있는 에피소드가 든 폴더를 지운 뒤 저장이 되지 않던 오류, 폴더를 에피소드 안으로 끌어 넣던 문제, 빈 이름 저장 문제를 수정했습니다.
    • 서브 메뉴 설정창에서 마우스를 올리면 버튼이 겹쳐 보이던 문제, 대시보드·[구조]의 번역 누락, 일부 다크 테마 배색을 수정했습니다.

    • [트릿]의 [🎭 +감정] 버튼으로 '주요 사건'을 [감정]에, [💬 +대표 대사] 버튼으로 '주요 대사'를 [캐릭]에서 고른 캐릭터의 '대표 대사'에 태그로 바로 추가할 수 있습니다.
    • [캐릭]에서 캐릭터를 추가하면 [타임]에 그 캐릭터의 인물 트랙이 자동으로 생성됩니다.
    • [에피]에서 회차 이름을 바꾸면 [트릿]·[플롯]·[타임]·[메모]에 표시되던 '해당 회차' 표기도 함께 갱신됩니다.
  4. [메모] — [아이템] 모드 추가.
    • 아이템 목록을 카드 형식으로 기록하는 메뉴입니다.
    • 아이템 카드에 입력할 항목과 등급·종류를 사용자가 추가/삭제하거나 수정할 수 있습니다.
    • 아이템의 [등급]과 [종류]별로 필터링할 수 있습니다.
    • [획득 회차]와 [소유자]를 입력하면, [트릿]에서 그 회차에 [에피] 목록이 연결돼 있는 경우에 한해 [에피]의 '아이템' 항목, [트릿]의 '아이템 획득' 항목, 그 회차의 [타임] 박스와 [플롯] 박스에 아이템 이름이 태그로 자동 표시됩니다.

전역 검색+

집필 중 Ctrl + G 를 누르면 키보드 커서 근처에 검색 창이 뜹니다. 메모·게시판과 시놉·구조·에피·트릿·타임·캐릭·감정·관계·마인·플롯·로그의 내용을 한 번에 검색합니다.

  • 검색어를 입력하고 Enter 를 눌러 검색합니다. (한글 조합 중 부분 검색을 막기 위해 Enter 로만 실행됩니다.)
  • 결과는 ↑ ↓ 로 이동, Enter 로 열기, Esc 로 닫습니다.
  • 결과를 고르면 해당 서브메뉴 패널이 열리고, 그 항목이 있는 탭·회차·구조 화면으로 이동해 검색어를 형광펜으로 표시합니다.

집필 도중 잘 기억나지 않는 설정이나 이름을 찾을 때 도움이 됩니다.

내부 링크 (하이퍼링크)+

서브메뉴(시놉·캐릭·구조·게시판 등)의 자료끼리 서로 이어 볼 수 있게 내부 링크를 걸 수 있습니다. 예를 들어 시놉시스에 나오는 인물 이름에 링크를 걸어 두면, 그 이름을 눌러 곧바로 캐릭터 자료로 건너뛸 수 있습니다.

링크 거는 법

  • 서브메뉴 패널(좌클릭으로 연 패널 또는 우클릭으로 연 두 번째 패널)의 입력칸에서 링크를 걸 글자를 드래그해 선택합니다.
  • Ctrl + L 을 누르면 링크 만들기 창이 뜹니다. 선택한 글자가 위에 표시됩니다.
  • 검색어를 입력하고 Enter 를 눌러 이동 대상(다른 서브메뉴의 자료)을 찾습니다. 항목을 고르면 반대쪽 패널에서 미리보기됩니다.
  • [링크 등록] 을 누르면 선택한 글자에 밑줄이 그어지고 파란색으로 표시됩니다.

링크 따라가기

  • 파란색 링크 글자를 클릭하면 대상 자료가 열립니다. 패널1의 링크를 누르면 패널2에서, 패널2의 링크를 누르면 패널1에서 열립니다.
  • 등록한 링크는 작품 폴더의 hyperlinks.json 에 함께 저장되어, 패널을 닫았다 다시 열어도 유지됩니다.

예시: '김 여주' 텍스트를 드래그 → Ctrl + L → 링크 만들기 창에서 '[캐릭] 김 여주' 선택 → 저장. 이후 '김 여주'를 클릭하면 [캐릭]의 김 여주 창으로 이동합니다.

책갈피 만들기 · 이동하기

  • Ctrl + D — 커서가 있는 문장에 책갈피를 켜거나 끕니다.
  • Ctrl + 1~9 — 수동 책갈피(Ctrl+D로 만든 것) N번째로 바로 이동합니다.

  • 팝업 맨 아래 "숨김" 체크박스로 본문에 표시되는 빨간 번호(⑴⑵⑶…)를 켜고 끌 수 있습니다.

*화면은 EPUB 파일에 들어가는 내용(제목·이미지·상자의 모양, 쪽 나누기 위치)을 그대로 보여 줍니다. 다만 실제 전자책 앱은 글꼴·글자 크기·줄 간격을 자기 설정대로 다시 배치하므로 쪽이 나뉘는 자리는 다를 수 있습니다.*

화면이 곧 EPUB 모습 — 바로 꾸미기

  • 보이는 그대로 — 제목은 큰 굵은 글씨, 이미지는 그림 그대로, 상태창·메시지는 테두리 상자로 보이고, 글을 그 자리에서 바로 고칠 수 있습니다. 예전의 편집 모드·뷰어 모드 전환은 없어졌습니다. 쪽 나누기는 글 높이를 차지하지 않으므로, 쪽 나누기로 시작하는 쪽의 위쪽에 띠로 나타납니다(✕ 로 지울 수 있습니다).
  • 넣는 방법 — 위쪽 마커 버튼을 클릭하면 커서 위치에, 버튼을 페이지로 끌어다 놓으면 파란 선이 보이는 그 자리에 들어갑니다. 상태창·메시지 안쪽에는 놓을 수 없고 그 앞이나 뒤로 맞춰집니다. 끌면서 페이지의 맨 위·아래 가장자리에서 잠깐 기다리면 쪽이 넘어갑니다.
  • 옮기기·삭제·수정 — 제목·이미지·상태창·메시지 위에 마우스를 올리면 나타나는 탭에서, 점 손잡이를 끌어 다른 자리로 옮기고 X로 지웁니다. 이미지·상자는 더블클릭해 내용을 고치고(제목 글은 그 자리에서 바로 고칩니다), 오른쪽 클릭하면 수정·복제·위로·아래로·삭제 메뉴가 뜹니다.
  • 글자 서식 — 글을 고른 뒤 B·I·A·BG 버튼으로 굵게·기울임·글자색·배경색을 입힙니다(굵게·기울임은 한 번 더 누르면 해제). 상태창·메시지 안의 글에도 적용됩니다.
  • 키보드 — 상자 안에서 Enter 는 줄을 늘리고, 빈 마지막 줄에서 Enter 를 누르면 상자를 빠져나갑니다. 탭으로 카드를 선택하고 Delete나 Backspace를 누르면 카드 전체가 지워지고, Ctrl+Z로 되돌립니다. 카드가 선택된 채로 글을 치면 카드 뒤 새 줄에 써집니다. 카드를 복사(Ctrl+C)해 붙여넣으면(Ctrl+V) 카드로 되살아납니다.
  • 저장 반영 — 화면에서 고친 내용은 그대로 EPUB 파일 저장에 반영되며(이미지도 놓은 자리에 들어갑니다), 글자 크기·줄 간격·판형을 바꿔도 사라지지 않습니다.

여러 회차를 한 번에 EPUB으로

플랫폼(리디·카카오·시리즈) 버튼 줄 오른쪽의 [📚 여러 회차 EPUB 변환]을 누르면, 바인더의 에피소드 목록에서 여러 회차를 체크로 골라 간단한 서식(문단만)으로 하나의 EPUB 파일로 합칠 수 있습니다. 고른 순서가 아니라 항상 바인더 순서대로 합쳐지며, 새 회차가 시작되는 부분은 자동으로 쪽이 나뉩니다. (제목·상태창·이미지 등 세밀한 서식을 넣고 싶다면 위의 한 회차씩 변환하는 방식을 이용해 주세요.)

투고+
  • [투고일]과 [회신일]을 YY-MM-DD 형태로 입력하면 [회신 기간]이 영업일 기준으로 자동 계산됩니다.
  • [투합 여부]·[자사 양식]·[피드백]은 클릭으로 빈칸/O/X를 전환합니다. 투합 여부가 O면 자동으로 투합탭에 생성됩니다.
  • 상단의 [작품 선택]으로 다른 작품의 투고 현황도 확인·입력할 수 있습니다.
  • 투합탭에서 [계약 체결]을 체크하면 계약탭 목록에 자동 생성됩니다. [계약탭]의 '+계약 추가'로 출판사와 계약 작품을 입력합니다.
  • 완고일·런칭일·표지 제안서 마감일을 입력하면 [일정] 캘린더에 자동으로 일정이 추가됩니다.
수익+
  • 상단 탭에서 작업 중인 작품과 전체 작품의 수익을 월별/연도별/연재 유형별로 확인합니다.
  • 줄 추가 / 플랫폼 추가 — [+ 줄 추가], [+ 플랫폼 추가]로 항목을 늘립니다. 플랫폼은 우클릭으로 이름·순서를 변경합니다.
  • [시놉]에서 설정한 유형(연재/단행/초단)과 작품 리스트의 필명을 기준으로 수익이 자동 분류됩니다.
  • [합계]는 월별 수익, [total]은 전체 합산을 보여줍니다.
일정+
  • 일정 추가 — [+일정 추가]로 내용과 기간을 입력하면 달력에 생성됩니다.
  • 일정 수정·삭제 — 달력에서 우클릭해 수정하거나 삭제합니다.
  • 디데이 추가 — [+일정 추가] 또는 [일정 수정]에서 [중요 D-DAY]를 체크하고 저장합니다.
  • 할 일 추가 — 입력창에 할 일을 적고 엔터를 누릅니다.
일지+
  • 월 목표 — 입력칸에 목표를 작성하고 엔터를 누릅니다.
  • 작업 데이터 — 작품명, 작업 유형(구상/초고/퇴고/작교/인풋/기타, 복수 선택 가능), 시작·종료 시간, 총 작업 시간(분), 글자수, 기분(복수 선택 가능), 인풋한 작품·회차를 기록합니다.
  • 작업 현황 연동 — 그 날의 작업 현황이 있으면 작품명(작품마다 태그)·총 작업 시간(실행 시간)·글자수(타이핑 글자 수)가 자동으로 입력됩니다. 직접 고친 칸은 덮어쓰지 않습니다.
  • 할 일 — [일정]에서 입력한 할 일을 확인·추가할 수 있습니다.
  • 통계 — 해당 월·연도의 작업일 수와 누적 글자수를 확인합니다.
  • 하루 목표 글자수 — 목표치를 설정하면 한 달간의 달성 현황을 그래프로 볼 수 있습니다.
  • 일지 — 선택한 날짜의 일지를 자유롭게 입력합니다.
출판+

하단의 '출판사 추가'로 출판사를 추가하거나, 상단의 '설정' 버튼으로 출판사를 추가·삭제하고 기록하고 싶은 항목을 추가할 수 있습니다.

왼쪽 출판사 목록과 오른쪽 내용 영역 경계의 손잡이를 눌러 목록을 접거나 펼칠 수 있습니다.

인풋+

인풋은 내가 쓰는 작품이 아니라, 다른 작품을 읽으면서 남기는 독서 기록 도구입니다. 좋아하는 웹소설을 분석하며 얻은 인사이트를 회차별로 정리해두고, 나중에 검색해서 다시 꺼내볼 수 있습니다.

1. 화면 구성

  • 왼쪽 – 작품 목록 : 내가 읽고 기록 중인 작품들
  • 가운데 위 – 회차 바 : 선택한 작품의 회차 목록 (기본 정보 + 모아보기 + 1화~10화)
  • 오른쪽 – 기록 영역 : 선택한 회차에 내용을 입력하는 곳

2. 작품 추가·검색·삭제

  • 작품 추가 : 왼쪽 하단 [＋ 작품 추가] 버튼을 눌러 읽은 작품을 등록하세요. 추가하면 기본 정보 + 1화~10화 회차가 자동 생성됩니다.
  • 검색 : 검색창에서 전체 / 키워드 / 분위기 / 장르 중 하나를 골라 검색어를 입력하면 해당하는 작품만 목록에 남습니다.
  • 삭제 : 작품 추가 버튼 옆의 🗑️ 버튼으로 선택한 작품을 삭제합니다. 회차와 기록이 모두 함께 삭제되니 신중하게 사용하세요.

3. 회차 다루기

  • 회차 바는 마우스로 드래그하면 좌우로 스크롤됩니다. 버튼을 짧게 클릭하면 그 회차가 선택됩니다.
  • 맨 오른쪽 [＋ 회차 추가] 버튼을 누르면 다음 회차가 바로 추가됩니다.

4. 기록 항목

  • 기본 정보 (작품 전체) : 제목 · 작가 · 장르 · 플랫폼 · 별점 · 키워드 · 프로모션 · 분위기 · 댓글 반응 · 후기
  • 각 회차 : 전개 속도(★10점) · 장면 요약 · 담긴 정보 · 물리적 변화 · 정보적 변화 · 관계적 변화 · 주인공의 감정 변화 · 서브인물의 감정 변화 · 시작 문장 · 후킹 · 개인 별점(★10점) · 평가 이유
  • ⭐ 전개 속도, 개인 별점 항목은 별을 클릭해 10점 만점으로 채점합니다. 같은 별을 다시 누르면 점수가 취소됩니다.

5. 항목 커스터마이징

  • 오른쪽 위 [⚙ 설정] 버튼을 누르면 현재 회차(또는 기본 정보)의 항목을 직접 바꿀 수 있습니다.
  • 항목 추가 · 삭제가 가능하고, 목록을 드래그해서 순서도 바꿀 수 있습니다.

💡 활용 팁
